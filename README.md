# Bandeh

Bandeh is an open-source business automation system that acts as a digital worker for businesses.

It connects services such as messaging platforms, CRM, inventory, payments, and fulfillment, and uses AI to help automate repetitive business tasks and workflows.

**You give the order. Bandeh does the work.**
