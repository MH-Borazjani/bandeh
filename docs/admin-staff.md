# مدیریت کاربران پرسنل و دسترسی به پنل ادمین (Admin & Staff Management)

این سند راهنمای ایجاد و ارتقای اولین کاربر پرسنل/ادمین جهت مدیریت سفارش‌ها و نظارت بر فروشگاه است.

## پیش‌زمینه و سطوح دسترسی (RBAC)

مدل کاربر در سیستم دارای سه سطح دسترسی است:
- `customer`: مشتری عادی، فقط به سبد خرید، فرآیند تسویه حساب و سفارش‌های خود دسترسی دارد.
- `staff`: پرسنل فروشگاه، به بخش مدیریت سفارش‌ها (`/admin/orders` و `/admin/orders/{id}`) دسترسی دارند و می‌توانند مرسولات را ارسال کرده و کد رهگیری ثبت کنند.
- `admin`: مدیر کل، علاوه بر دسترسی‌های پرسنل، به داشبورد و آمار کلی فروشگاه (`/admin/overview`) دسترسی کامل دارد.

## نحوه ایجاد اولین کاربر مدیر/پرسنل

از طریق اسکریپت CLI داخل مخزن می‌توانید شماره موبایل مالک یا پرسنل را به عنوان کاربر ادمین یا پرسنل ثبت کنید.

### دستور اجرای مستقیم در هاست:

```bash
# ایجاد یا ارتقای کاربر به نقش مدیر کل (Admin)
uv run python scripts/create_staff_user.py 09121234567 --role admin

# ایجاد کاربر به نقش پرسنل پردازش سفارش‌ها (Staff)
uv run python scripts/create_staff_user.py 09129876543 --role staff --first-name "علی" --last-name "محمدی"
```

### اجرای اسکریپت درون کانتینر داکر:

```bash
docker compose exec web python /app/scripts/create_staff_user.py 09121234567 --role admin
```

## ورود به پنل ادمین

1. کاربر پس از ثبت در دیتابیس، به آدرس `/auth/login` مراجعه کرده و شماره موبایل خود را وارد می‌کند.
2. کد تأیید ۵ رقمی پیامک شده را وارد کرده و لاگین می‌کند.
3. پس از احراز هویت، با دسترسی به آدرس‌های زیر وارد پنل مدیریت می‌شود:
   - **داشبورد آمار کلی:** `/admin/overview`
   - **مدیریت سفارش‌ها و آماده‌سازی مرسولات:** `/admin/orders`
