# سرور MCP فروشگاه — چی هست و چطور وصل می‌شوی

## به زبان ساده

سرور MCP یعنی هوش مصنوعی (ChatGPT ،Gemini ،Claude) می‌تواند مستقیم با فروشگاه حرف بزند:
کالا جستجو کند، قیمت و موجودی را بگوید، به سبد خرید اضافه کند و سفارش بسازد.
آدرس سرور این است:

```
https://genabay.ir/mcp
```

تا وقتی فروشگاه روی سرور بالا نیامده، همین آدرس روی لپ‌تاپ این است:

```
http://localhost:8000/mcp
```

## دو بخش: خواندن برای همه، خرید فقط با توکن

**خواندن — بدون ورود:**
- `search_products` — جستجوی کالا (نام، دسته، نو یا دست دوم)
- `get_product` — یک کالا با قیمت و موجودی
- `list_categories` — همه دسته‌ها

**خرید — فقط با توکن شخصی:**
- `get_cart` ،`add_to_cart` ،`remove_from_cart` — سبد خرید
- `create_order_draft` — ساخت پیش‌نویس سفارش (فقط قیمت‌ها قفل می‌شوند؛ پول و رزرو کالا نه)
- `cancel_order` — لغو سفارشِ هنوز پرداخت‌نشده
- `get_payment_link` — گرفتن لینک پرداخت زیبال

## توکن را از کجا بگیرم؟

1. وارد حساب شو (`/auth/account`).
2. در بخش «اتصال هوش مصنوعی (MCP)» یک نام بنویس و «ساخت توکن» را بزن.
3. توکن **فقط همین یک بار** نمایش داده می‌شود؛ همین حالا کپی‌اش کن.
   اگر گمش کردی، توکن را باطل کن و یکی تازه بساز.
4. در برنامه هوش مصنوعی، موقع اضافه کردن سرور MCP، توکن را به‌عنوان
   `Authorization: Bearer <token>` بده (بعضی برنامه‌ها یک قسمت جدا برای توکن دارند).

هر توکن فقط به حساب خودت وصل است و هر وقت بخواهی از همان صفحه باطلش می‌کنی.

## مهم‌ترین قانون: هوش مصنوعی هیچ‌وقت خودش پول نمی‌دهد

`get_payment_link` فقط لینک صفحه بانک را برمی‌گرداند.
هوش مصنوعی آن لینک را به تو می‌دهد و **تو** در صفحه بانک پرداخت می‌کنی.
سفارش هم فقط پیش‌نویس است تا وقتی خودت پرداخت را انجام بدهی.

## برای برنامه‌نویس‌ها (خلاصه فنی)

- پروتکل: MCP روی Streamable HTTP، با SDK رسمی پایتون (`mcp>=1.0,<2`) و FastMCP.
- کد: `app/e-commerce/integrations/mcp_server.py` — ابزارها + میان‌افزار احراز هویت
  (`MCPAuthMiddleware` توکن را یک بار در هر درخواست HTTP بررسی می‌کند و شناسه کاربر را
  در `scope["mcp_user_id"]` می‌گذارد).
- جدول‌ها (مهاجرت 010): `personal_access_tokens` (فقط هش SHA-256 توکن ذخیره می‌شود)
  و `cart_items` (سبد خرید سرور، یک ردیف برای هر مشتری و کالا).
- سبد خرید سایت هنوز در مرورگر است (localStorage) و سبد MCP جداست؛ یکی کردن
  آن دو، کار بعدی است، نه این مرحله.
- تست‌ها: `tests/check_mcp_server.py` — همه ابزارها روی HTTP واقعی با JSON-RPC.
